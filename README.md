# ⚡ Manas Arora | Developer Portfolio

> "Building the Unknown, One Line at a Time."

A sleek, high-performance, and fully responsive portfolio website designed to showcase my journey as a Full Stack Developer. Built with a focus on aesthetics, smooth interactions, and modern web standards.

## ✨ Features

- **🎨 Premium Aesthetic**: Deep dark mode with vibrant mesh gradients and glassmorphism elements.
- **🎭 Cinematics Animations**: Powered by **GSAP** and **ScrollTrigger** for smooth reveal effects and interactions.
- **🖱️ Interactive Experience**: Custom magnetic cursor, hover effects, and micro-interactions.
- **📱 Fully Responsive**: Optimized for all devices, featuring a "App-like" bottom navigation for mobile users.
- **🔗 Dynamic Content**: Automatically fetches and showcases selected top repositories from GitHub.
- **🚀 Performance**: Blazing fast load times powered by **Vite**.

## 🛠️ Tech Stack

- **Core**: HTML5, CSS3 (Modern Variables & Flexbox/Grid), JavaScript (ES6+ Modules)
- **Tooling**: [Vite](https://vitejs.dev/) (Next Generation Frontend Tooling)
- **Animations**: [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform)
- **Fonts**: Inter & Outfit (Google Fonts)

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/manas0x/portfolio.git
   cd portfolio
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:5173`.
